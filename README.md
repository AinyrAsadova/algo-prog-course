## ПР1. Ответы на контрольные вопросы

**1.** C# сначала компилируется, и ошибки находятся до запуска программы. В Python код идёт построчно, поэтому ошибка видна только когда дойдёт до этой строки.

**2.** Сначала программа собирается (компилируется), потом запускается.

**3.** В bin/ и obj/ лежат файлы, которые создаются при сборке сами. Их можно пересобрать в любой момент, поэтому в Git их хранить не надо, они только занимают место.

**4.** git commit сохраняет изменения у меня на компьютере. git push отправляет их на GitHub.

**5.** При + строки склеиваются по кусочкам, и можно забыть пробел. При $"..." переменные вставляются прямо в строку в {}. Интерполяция удобнее, потому что так проще читать и меньше ошибок.

**6.** Получится целое число, дробная часть пропадёт: 25 / 4 будет 6. Чтобы было 6,25, надо сделать одно число double: (double)25 / 4.

**7.** const нельзя изменить после объявления, а обычную переменную можно. Например, const double VatRate = 0.20;, потому что НДС в программе меняться не должен.

**8.** Top-level statements это когда код пишется сразу в Program.cs, без класса Program и метода Main. Работает так же, но записывается короче.
